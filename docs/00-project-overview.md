# ClipVault

## Project Goal

ClipVault is a secure clipboard-sharing application built to demonstrate modern Full Stack Development, DevOps, Cloud, and Security Engineering practices.

The project is intentionally designed as a production-style SaaS application.

---

## Technology Stack

- FastAPI

- Alembic

- JWT Authentication
